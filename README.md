## 技术栈定调

- **Astro 7.3.5 + Tailwind 4.3.3 + npm**（pnpm 已于 2026-10-06 卸载，勿用）
- 文章 = 纯 Markdown，支持扁平式与目录式两种组织，push 即发布
- 静态产物 → GitHub Pages，单条部署通道
- 原则：不装重型主题、不带 CMS、无数据库；维护面 = **改 config + 写文章**

## 已定但容易忘的硬约束

- **永久不做评论功能**（任何形式）
- **永久非商用** —— 这是专辑封面使用、字体许可等决策的前提；前提一改，相关决策需全部重评
- 分类单值且稳定、标签多值且灵活；**文件夹不参与 URL 语义**
- 图片放 `src/` 下，**不放 `public/`**（放 public 会绕过图片优化管线）
- 正文栏宽 680px + 右栏 200px 的两栏制，**所有块左对齐，不要用 `mx-auto` 居中单栏**

## 经验教训（写新代码时避开）

- 部署只留**一条**通道（Actions），别再手写 deploy 脚本
- 功能开关和代码必须同步：不上线的功能就别把依赖装进来
- `.env` 永远 gitignore（旧仓库曾把 `.env` 提交进公开仓库）
